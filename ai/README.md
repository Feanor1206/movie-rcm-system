# AI & Recommendation Engine

This directory contains research, dataset preparation, training pipelines, model checkpoints, and evaluation benchmarks for the movie recommendation algorithms.

## Structure
- `models/`: Model architecture definitions and exported weights / ONNX artifacts.
- `training/`: Training scripts, hyperparameter tuning, and distributed training jobs.
- `datasets/`: Dataset download scripts, preprocessing pipelines, and feature extractors.
- `evaluation/`: Offline evaluation metrics (NDCG@K, Recall@K, MAP), A/B testing simulators.
