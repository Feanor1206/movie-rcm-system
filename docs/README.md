# Tài liệu hỗ trợ

- `contracts/`: lược đồ danh mục, dữ liệu mẫu và trình kiểm tra Python.
- `fixtures/`: dữ liệu danh mục và ánh xạ video cố định cho kiểm thử.
- `benchmarks/`: bộ truy vấn đánh giá.
- `runbooks/db/`: lược đồ SQL phục vụ thiết lập cơ sở dữ liệu.

Cách cài đặt và chạy nằm trong [README chính](../README.md). Kết quả sinh vào `reports/` hoặc `reviews/evidence/` được Git bỏ qua.
